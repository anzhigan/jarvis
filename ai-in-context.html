Build NoteAttachment API

edited 2 days ago backend tiptap jarvnote

Файлы внутри заметки — это не дополнение, а первоклассная единица контента. У них есть собственное API, отдельный storage в MinIO, и узел в TipTap-документе.

Архитектурное решение: inline atom node

В TipTap есть два пути представить attachment: как mark вокруг текста (вариант, который мы отвергли) или как node. Mark — это форматирование, которое оборачивает текст и сохраняет cursor inside. Node — это отдельная единица, которая не имеет текста внутри.

Выбираем node с конфигурацией: group: 'inline', inline: true, atom: true, selectable: false. Atom означает «неделимый» — курсор не может стоять внутри, только до или после.

Endpoint: POST /notes/{id}/attachments

Multipart upload, validates mime type, uploads to MinIO, returns presigned URL + S3 key. Backend хранит metadata в note_attachments таблице.

POST /notes/abc-123/attachments
Content-Type: multipart/form-data

→ 201 Created
{
  "id": "att-xyz-456",
  "url": "https://...signed=true&expires=...",
  "key": "notes/abc-123/specdraft.pdf"
}
Test your memory. I read this note (~850 words) and can build a quick 8-question quiz to check what stuck. Takes ~30 seconds.

NodeView — React component

TipTap NodeView позволяет рендерить узел кастомным React-компонентом. Внутри — настоящий <a> тег с динамическим href, обновляющимся на каждом взаимодействии (mousedown, mouseenter, focus, touchstart), чтобы token не протухал к моменту middle-click открытия.

Заметь: ничего не выпрыгивает. AI-nudge — это просто блок в ленте чтения. Можно прокрутить мимо, можно dismiss × кнопкой, можно начать quiz. Никакого FOMO, никакого «not now» modal.

12 · Generate tasks

Generate tasks · action items из материала

AI читает заметку (или goal, или sprint) и предлагает задачи к добавлению. Каждая задача показывает: title, цитата-источник («откуда я её взяла»), и куда предлагается прикрепить (goal/step). User выбирает галочками что добавить — это не auto-merge, это ассистент с подтверждением.

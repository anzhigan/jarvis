00 · Foundation

Indigo Editorial

Knowledge base, не SaaS. Письмо, чтение, мышление — главные действия. Система намеренно медленная, тёплая, сделанная руками. Бумага, не экран. Засечки, не sans. Тонкие линии, не drop-shadow. Чёткие сжатые радиусы, не закругления Material.

01

Hairlines over shadows

Бумажный canvas — глубина читается границами 1px. Тени появляются только на hover/popover/modal как событие, не как постоянная декорация. Никаких mass-market drop-shadow стэков.

02

Three fonts, three roles

Fraunces для display (заголовки, числа, акценты — character). Source Serif 4 для body (длинное чтение — comfort). Inter для UI (метки, кнопки — clarity). Никаких смешений: каждый шрифт делает одну работу.

03

Cool ink on warm paper

Canvas #FCFCF9 — тёплый off-white. Текст #15202A — холодный slate. Контраст 13:1 (AAA), но без «офисной» белизны экрана. Глаз отдыхает на длинных note-страницах.

04

Editorial accents, не tailwind rainbow

5 акцентов (moss, ochre, rust, slate, walnut) — землистые, подобраны вручную. Каждый цвет несёт смысл: moss = рост/успех, ochre = внимание, rust = разрушение, slate = нейтрал, walnut = глубина. Никаких amber/cyan/violet — это другая система.

Typography

Три гарнитуры. Каждая делает одну работу. Никаких смешений ролей — Fraunces никогда не идёт в кнопку, Inter никогда не идёт в body.

05 · Foundation

Shadows — hairline-first

Default — только 1px hairline ring. Тени появляются как событие: hover, popover, modal, focus. Никогда — как декорация.

--sh-card
0 0 0 1px hairline
--sh-card-hover
+ 2px 6px 6% ink
--sh-popover
+ 8px 24px 10% ink
--sh-focus
3px indigo-tint

sh-modal — наибольший: + 24px 64px 14% ink. Используется только для full-screen modals — даёт ощущение «всё остальное под полотном».

06 · Foundation

Motion — deliberate, settle

Один ease, два duration. Никаких bounce, никаких spring — это editorial, не toy.

--ease

cubic-bezier(0.32, 0.72, 0.30, 1)

Slow start, settle. Чувствуется как «вещь устанавливается на место», не «прыгает».

--dur-fast / --dur-med

140ms · 220ms

fast для hover/color flip. med для panel slide-in, dropdown reveal.

99 · Hygiene

What we dropped

Эти токены / шрифты / цвета жили в системе и больше не нужны. Каждое удаление освобождает дизайн-словарь и снижает энтропию. Список — обязательная часть док-та: новый дизайнер должен знать что не воскрешать.

  • --font-sans (system stack)

    Дубль --font-ui. Inter покрывает UI. System fallback теперь внутри font-ui declaration.

  • --font-serif (Tiempos Text)

    Дубль --font-body. Source Serif 4 уже стоит — никакой Tiempos нигде не подключён, призрак.

  • --brand-50 → --brand-900 (10-step ramp)

    Tailwind-style ramp избыточен. Нужны только --indigo + -soft + -tint. Никаких brand-300 / brand-700.

  • --accent-notes / -goals / -routines / -sprints / -analysis (Tailwind 500 rainbow)

    Amber #F59E0B, emerald #10B981, cyan #06B6D4, violet #A855F7 — генерик SaaS-палитра. Сейчас идентичность секций через editorial: indigo / moss / ochre / slate / walnut. Они несут смысл.

  • --bg-app / -shell / -card / -elevated / -hover / -active / -input стек

    7 переменных под фон. Замена: --paper / --cream / --soft / --rail-bg — 4 ступени, ясная иерархия.

  • --fg-primary / -secondary / -tertiary / -muted / -faint / -inverse

    Дубль ink-системы. Заменено: --ink / --ink-2 .. --ink-5. Mnemonic чище.

  • --line / -strong / -faint

    Дубль hairline. Заменено: --hairline / -strong / -faint. Имя точнее (это волосок, не line-через-весь-блок).

  • --radius / -sm / -md / -lg / -xl (shadcn aliases)

    8 / 6 / 8 / 12 / 14 — пять значений, два дубля. Editorial система — 4 чёткие ступени: 2 / 5 / 6 / 999.

  • --r-card: 12px (legacy)

    Конфликт с editorial --r-card: 6px. 12px — squishy, не для нашего голоса.

  • shadcn shim: --background / --card / --popover / --secondary / --muted / --accent / --destructive / --border / --input / --ring / --primary-foreground + sidebar-*

    Tailwind v4 / shadcn alias-щит. Использовался только в одном-двух местах, давно вычищенных. Сейчас все consumer'ы читают editorial tokens напрямую.

  • --ease-spring · --dur-base · --dur-slow

    Spring ease для toy-style анимаций — не наш язык. dur-base 240ms / dur-slow 380ms — три duration избыточно, остались два: fast 140ms + med 220ms.

  • --text-md duplicate (14.5 vs 15.5)

    Одна переменная — одно значение. 15.5 — canonical body editor size, побеждает.

  • Dark mode duplicate brand ramp

    В [data-theme="dark"] сидел ещё один brand-50..900 ramp под legacy mobile shell. Не нужен — все consumer'ы переехали.

  • --bg-overlay light/dark

    Один токен на всю систему: rgba(15, 24, 32, 0.40) для light, rgba(0, 0, 0, 0.60) для dark. Раньше было 2 разных значения в legacy.

Принцип хранения. Если токен встретился < 3 раз в коде — проверь, есть ли альтернатива. Если есть semantic-alias к другому токену (success → moss) — это значит система знает, что они одно и то же. Тогда оставляй один.

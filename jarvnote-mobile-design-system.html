Jarvnote · Design System

Mobile · Indigo Editorial

A focused, single-thumb UX layer atop the shared Jarvnote token base. Tuned for iOS 17/18: large titles, translucent materials, continuous radii, 44pt minimums, and bottom-up modality. Quick capture beats rich authoring; one CTA per screen; gestures replace menus.

Principles

The five rules that resolve ambiguity. When in doubt, default to whichever interpretation honors more of these.

01 · Thumb-first
Every primary action lives in the bottom third or as a sticky CTA. Top-right is reserved for nav, never for action.
02 · One CTA per screen
Exactly one filled-primary button visible at any time. Everything else is tinted, plain, or a row action.
03 · Bottom modality
Sheets slide from bottom, never from the side. Side-drawers are desktop-only — they break the spatial model on a phone.
04 · Quick over rich
Mobile is capture & check-in. Full authoring is allowed but never the default flow; surface "more" via expand or tap-into-detail.
05 · Gestures replace menus
Swipe-left for row actions. Long-press for context menus. Tap is committal — never use tap for "open menu" when an action button would do.
06 · 16px text floor
Inputs and primary body never go below 16px on iOS — anything smaller triggers automatic zoom-to-fit on focus, which feels broken.
07 · Shared business logic
UI splits across features/mobile and features/<area>; hooks and lib functions are shared. Never duplicate calc logic between platforms.
08 · Honor reduced motion
Every transition is wrapped in prefers-reduced-motion. Sheets, fades, springs all degrade to instant-snap when set.
